# Spearhead — Forgeruines de Hashut

Mémo Warhammer Age of Sigmar Spearhead (unités, règles, phases), installable en PWA et utilisable hors ligne.

Mise à jour : après toute modification d'un fichier, changer `VERSION` dans `sw.js` (ex. `hashut-v2`) pour que les appareils récupèrent la nouvelle version.
